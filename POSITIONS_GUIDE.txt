================================================================================
                        WORKFLOW EXPLANATION
================================================================================

How the automation works:
1. Excel file is read -> Each row has a "Decoration Location" column
2. System detects garment type from location name (T-SHIRT, CAP, BAG, BLANKET)
3. MediaPipe detects body landmarks in the image (shoulders, elbows, hips, etc.)
4. Detector files calculate logo coordinates using landmarks + offsets
5. Logo is placed at calculated coordinates in Photoshop

YOUR MAIN GOAL: Find best coordinates for each position
- Each position needs (xOffset, yOffset) values
- These are pixel adjustments from the detected body landmark
- You'll need to test with sample images and adjust values

================================================================================
                    HOW TO ADD/MODIFY A POSITION
================================================================================

To add a new position, edit the appropriate detector file:

Example - Adding "CENTER-BACK" to garmentDetector.py:

GARMENT_MAPPING = {
    ...existing positions...
    
    "CENTER-BACK": {
        "landmarks": ["LEFT_SHOULDER", "RIGHT_SHOULDER"],  # Body parts to use
        "method": "midpoint",    # How to combine landmarks
        "xOffset": 0,            # Horizontal adjustment (+ = right, - = left)
        "yOffset": 150           # Vertical adjustment (+ = down, - = up)
    }
}

METHODS AVAILABLE:
- "single"      -> Use one landmark directly
- "midpoint"    -> Average of multiple landmarks
- "weighted"    -> Weighted average (use "alpha" parameter)
- "shoulderBias"-> Bias toward left or right shoulder (use "side" parameter)

LANDMARKS AVAILABLE (from MediaPipe):
- NOSE, LEFT_EYE, RIGHT_EYE, LEFT_EAR, RIGHT_EAR
- LEFT_SHOULDER, RIGHT_SHOULDER
- LEFT_ELBOW, RIGHT_ELBOW
- LEFT_WRIST, RIGHT_WRIST
- LEFT_HIP, RIGHT_HIP
- LEFT_KNEE, RIGHT_KNEE
- LEFT_ANKLE, RIGHT_ANKLE
